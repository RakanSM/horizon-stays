# Bilingual Typography Preview — 2026-08-25

The public Horizon typography layer now scopes Arabic and English font stacks by the live document language set by the language provider. Arabic uses an IBM Plex Sans Arabic/Tajawal stack with more generous display line-height; English uses Space Grotesk for display and labels with a system body stack.

Local browser inspection confirmed the primary Arabic and English hero layouts use the respective scale without clipping. The public type scale now covers navigation, hero, search controls, section headings, property cards, scroll scenes, map cards, footer links, and the mobile breakpoint.
